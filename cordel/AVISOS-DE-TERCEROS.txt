AVISOS DE TERCEROS
==================

Cordel lleva dentro código de otros autores, usado sin cambios y con su permiso: el que dan sus
licencias, que piden que estos avisos acompañen al programa. Valen para Cordel.exe y para lo que
instala Cordel-instalar.exe, en la versión 1.0.0.

Cordel en sí es de jguardiola-dev y tiene su propia licencia (MIT), en el archivo LICENSE.


QUÉ LLEVA DENTRO
----------------

1. La biblioteca estándar de Rust 1.100.0
   https://www.rust-lang.org
   Licencia: Apache-2.0 o MIT, a elección.
   Copyright: The Rust Project Developers (https://thanks.rust-lang.org).
   Lleva a su vez piezas de otros autores. El documento con todos sus avisos, tal como lo reparte
   Rust con esa versión, se publica con este archivo y se llama rust-COPYRIGHT-library.html (en el
   repositorio está en la carpeta avisos).

2. Las bibliotecas de Microsoft para hablar con Windows
   windows 0.62.2, windows-collections 0.3.2, windows-core 0.62.2, windows-future 0.3.2,
   windows-link 0.2.1, windows-numerics 0.3.1, windows-result 0.4.1, windows-strings 0.5.1,
   windows-threading 0.2.1, y el código que generan windows-implement 0.60.2 y
   windows-interface 0.59.3.
   https://github.com/microsoft/windows-rs
   Licencia: MIT o Apache-2.0, a elección. Aquí se usan con la MIT (texto A).
   Copyright (c) Microsoft Corporation.

3. rusqlite 0.43.0 y libsqlite3-sys 0.40.0
   https://github.com/rusqlite/rusqlite
   Licencia: MIT (texto B).
   Copyright (c) 2014 The rusqlite developers

4. SQLite 3.54.1 (va dentro de libsqlite3-sys)
   https://sqlite.org
   Es de dominio público y no pide aviso; se nombra para que la lista esté completa.

5. smallvec 1.16.5
   https://github.com/servo/rust-smallvec
   Licencia: MIT o Apache-2.0, a elección. Aquí, MIT (texto C).
   Copyright (c) 2018 The Servo Project Developers

6. bitflags 2.13.2
   https://github.com/bitflags/bitflags
   Licencia: MIT o Apache-2.0, a elección. Aquí, MIT (texto D).
   Copyright (c) 2014 The Rust Project Developers

7. fallible-iterator 0.3.0
   https://github.com/sfackler/rust-fallible-iterator
   Licencia: MIT o Apache-2.0, a elección. Aquí, MIT (texto E).
   Copyright (c) 2015 The rust-openssl-verify Developers

8. fallible-streaming-iterator 0.1.9
   https://github.com/sfackler/fallible-streaming-iterator
   Licencia: MIT o Apache-2.0, a elección. Aquí, MIT (texto F).
   Copyright (c) 2016 The fallible-streaming-iterator Developers

9. La biblioteca de C de Microsoft (la de Visual C++ y el SDK de Windows), enlazada dentro
   Su licencia no pide aviso; se nombra para que la lista esté completa.

Además, el instalador (Cordel-instalar.exe) y el desinstalador que deja están hechos con Inno Setup
(https://jrsoftware.org/isinfo.php), que lleva sus propios avisos dentro (texto G):
   Copyright (C) 1997-2026 Jordan Russell. All rights reserved.
   Portions Copyright (C) 2000-2026 Martijn Laan. All rights reserved.
